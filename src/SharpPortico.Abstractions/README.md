# SharpPortico.Abstractions

![SharpPortico](https://raw.githubusercontent.com/MPCoreDeveloper/SharpPortico/main/docs/assets/SharpPortico.jpg)

**Attributes and options consumed by the SharpPortico source generator.**

Defines the `[assembly: OpenApiToGrpc]` attribute (`SharpPortico` namespace) and its generation options — emitters (client/server/DI/proto), mapping rules, pagination detection, naming, and proxy mode.

This assembly ships inside the `SharpPortico.SourceGenerator` package (under `analyzers/dotnet/cs`), so you don't need to reference it separately.

📖 **Full documentation:** [SharpPortico on GitHub](https://github.com/MPCoreDeveloper/SharpPortico#readme)
